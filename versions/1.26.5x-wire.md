# Minecraft 1.26.50 stable native wire

The native model is stable protocol 2193 from gophertunnel
`7a556a07335b663744b50d38062636ad8283f314`. Minecraft 1.26.45/protocol 2169 is
historical, with the outgoing layouts at `7f058e5` and corrected optional
filtered inventory names at `283a5a9`.

The old `feat/all_26_u5` preparation used Preview 26/protocol 2192. Its final
API differences, packet fields and independent oracles have been rechecked for
the stable release. Registry-aware catalogues include protocol 2169.

## Protocol-2169 differences

- packet IDs 351 `SetPlayerFurnaceOptions` and 352 `RecordStarted` do not exist and are removed from both
  historical pools;
- `BossEvent` carries the removed player unique ID;
- `InventoryTransaction`, `InventoryAction`, `ItemStackResponse`, and `PlayerAuthInput` retain their outer
  presence booleans;
- `UseItemTransactionData` has no hand field;
- `MoveActorDelta` has no interpolation tick field;
- `PlaySound` has no range-bypass or playback-position fields;
- camera presets, environment attributes, entity diagnostics, text shapes, and dimension definitions omit the
  protocol-2193 additions;
- sub-chunk height maps contain 256 signed bytes rather than 272;
- the removed memory category at historical index 58 is translated explicitly.

Native-only packets are dropped. Boss registration events are also dropped because protocol 2193 no longer
carries the target player ID needed to represent them. New disconnect reasons are downgraded to unknown.

Additional independent populated inventory oracles use gophertunnel `283a5a9`.
They cover the signed interaction action, byte trigger/face fields, nested
inventory actions and present filtered custom names in both directions without
mutating input packets. Protocol-1001 oracles use `0a2ecd5` for shared camera,
boss, text-shape, environment-attribute and diagnostic payloads.

Common wire deltas are reused only where a historical adapter has no more
specific codec. Block/item/gameplay semantics never pass through an intermediate
version. Diagnostic categories resolve exact enum names; removed categories
become Unknown. The effective native sound update is the final Resume-named
variant, as corrected by upstream `b8bd735`.
