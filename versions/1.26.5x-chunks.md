# Minecraft 1.26.50 chunk boundary

Protocol 2193 represents a height map as 16 rows of 16 signed heights, with a
varuint row length before each row. Historical codecs flatten the native array
into exactly 256 signed bytes while preserving optional presence and cache data.
Independent populated historical byte oracles cover both directions.

Block palettes map by identifier and complete typed state before packing and
cache hashing. New stair corners and pane/bar/fence connections collapse to their
old client-derived states without changing live worlds or native palettes.

Dragonfly's generic BiomeRuntimeIDMapper capability also runs before packing and
hashing, including the 1.16.100 2D path. This native delta maps Dappled Forest
(195) to Forest (4). It does not claim a new audit of every biome introduced
between unrelated older releases.

Historical StartGame excludes native vanilla data-driven definitions. Protocol
419 still sends its exact full historical block palette. Consumer regressions
decode this boundary and check every native oak-stair, oak-fence and glass-pane
state against every configured adapter.

Saved chunks can retain their previous block version while lacking the new
derived properties. Dragonfly marks property-adding upgrades for neighbour repair
even when that version number is unchanged. Tests reproduce the skipped-repair
path without changing persisted maps. Real-client rendering and cold/warm cache
validation remain release gates.
